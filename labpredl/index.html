🏆 Уровень 4: Теория

Паспорт предложения

📋 Что нужно определить:

  • ✅ Вид по цели — повествовательное / вопросительное / побудительное
  • ✅ Интонация — восклицательное / невосклицательное
  • ✅ Распространённость — распространённое / нераспространённое

Пример:

"Какой красивый закат!"

  • 🔹 По цели: повествовательное (сообщает)
  • 🔹 По интонации: восклицательное (!)
  • 🔹 По наличию второстепенных: распространённое ("какой", "красивый")
